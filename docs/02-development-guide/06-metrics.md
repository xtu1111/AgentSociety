# 指标解读：情绪与采纳率

在回放页面的 **Metrics** 面板中，新增了两条与营销场景相关的指标曲线：平均情绪 (`avg_sentiment`) 和采纳率 (`adoption_rate`)。

## 图表解读

- **平均情绪 (`avg_sentiment`)**：反映当前所有用户对产品或话题的平均态度，数值范围为 -1~1，越接近 1 表示整体情绪越积极。
- **采纳率 (`adoption_rate`)**：表示已有多少比例的用户采纳了产品或观点，范围为 0~1。

在 Metrics 面板中，这两条曲线会同步展示，方便观察情绪变化是否会带来采纳行为的改变。

## 商业意义

- 持续上升的平均情绪意味着品牌形象提升或宣传策略有效，可用于评估营销文案、广告投放等举措的影响。
- 采纳率能够衡量市场渗透情况，帮助企业判断产品推广是否成功，以及是否需要进一步激励措施。

结合这两项指标，运营人员可以快速了解用户态度与行为之间的关系，从而及时调整营销策略。
